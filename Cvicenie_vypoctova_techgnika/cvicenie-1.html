ZHRŇ

TEORETICKÝ ZÁKLAD

Najprv
smer signálu.

Digitálny signál má dve logické úrovne: LOW (0) a HIGH (1). Mikrokontrolér číta vstupy a nastavuje výstupy.

A

INPUT — mikrokontrolér počúva

Tlačidlo pripojíme na digitálny pin. pinMode(BUTTON_PIN, INPUT); a potom digitalRead(BUTTON_PIN).

B

OUTPUT — mikrokontrolér riadi

LED pripojíme cez prúdový rezistor. pinMode(LED_PIN, OUTPUT); a digitalWrite(LED_PIN, HIGH/LOW).

C

Najprv konfigurácia, potom práca

Každý použitý pin nastav pomocou pinMode() vo funkcii setup(). Vstup čítaj a výstup riadi v loop().

D

LED vždy s rezistorom

Zapojenie: D8 → rezistor 220–330 Ω → anóda LED; katóda LED → GND. Rezistor obmedzuje prúd.

VZOROVÉ ZAPOJENIE

Tlačidlo rozhoduje, LED odpovedá

Základný variant v tomto cvičení používa externý pull-down 10 kΩ, aby bol vstup v oboch polohách definovaný.

ZAPOJENIE · PULL-DOWN

Tlačidlo na D2

D2 ↔ tlačidlo ↔ +5 V

D2 ↔ rezistor 10 kΩ ↔ GND

D8 → 220–330 Ω → anóda LED

katóda LED → GND

GND musí byť spoločný. Pred prepojením vodičov a zmenou zapojenia odpoj USB. LED má dlhšiu nožičku (anódu) smerom k rezistoru a D8.

ARDUINO IDE · ZÁKLADNÝ PROGRAM
const int LED_PIN = 8;
const int BUTTON_PIN = 2;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  pinMode(BUTTON_PIN, INPUT);
}

void loop() {
  int buttonState = digitalRead(BUTTON_PIN);

  if (buttonState == HIGH) {
    digitalWrite(LED_PIN, HIGH);
  } else {
    digitalWrite(LED_PIN, LOW);
  }
}

Pri tomto pull-down zapojení je uvoľnené tlačidlo LOW a stlačené HIGH.

KARTA 01 / ZÁKLAD

Tichý signál

Po stlačení tlačidla sa rozsvieti jedna LED. Po uvoľnení zhasne.

ÚlohaPouži INPUT, OUTPUT, digitalRead() a podmienku if/else.
Hotovo, keďLED reaguje iba počas stlačenia.
KARTA 02 / ROZŠÍRENIE

Potvrdenie odpovede

Krátke stlačenie rozsvieti LED a tá zostane svietiť aj po uvoľnení. Ďalšie stlačenie ju zhasne.

ÚlohaUlož stav LED do premennej a pri stlačení ho zmeň.
Hotovo, keďKaždé stlačenie zmení uložený stav raz.
KARTA 03 / ROZŠÍRENIE

Prepínač režimu

Jedno tlačidlo mení režim: LED bliká = otázka, LED svieti = odpoveď sa vyhodnocuje.

ÚlohaVytvor dva režimy a pre každý opíš, čo signalizuje.
Hotovo, keďOba režimy majú jasný a odlišný signál.
KARTA 04 / ROZŠÍRENIE

Semafor otázok

Dve tlačidlá predstavujú „mám otázku“ a „rozumiem“. Každé rozsvieti svoju LED.

ÚlohaPripoj dva vstupy a dva výstupy; otestuj aj obe tlačidlá naraz.
Hotovo, keďKaždá LED zodpovedá svojmu tlačidlu.
KARTA 05 / ROZŠÍRENIE

Dve odpovede

Tlačidlo A rozsvieti zelenú, tlačidlo B červenú LED. Tretí stav: pri oboch stlačených svietia obe.

ÚlohaNavrhni logiku pre dve samostatné podmienky.
Hotovo, keďOtestuješ A, B, obe naraz aj žiadne.

UČITEĽSKÉ POZNÁMKY · SKRYTÉ V POHĽADE ŽIAKA

Metodické vedenie hodiny

Pred začiatkom

Pripravte pre každú dvojicu Arduino Uno, LED, tlačidlo, rezistor LED 220–330 Ω, pull-down rezistor 10 kΩ a prepojovacie vodiče. Skontrolujte spoločnú GND a dohodnite pravidlo: káble sa menia len pri odpojenej USB napájacej šnúre.

Formujúce otázky

Pred zapojením: „Ktorý pin bude počúvať? Ktorý bude riadiť? Aký stav očakávaš pred stlačením?“ Po zapojení: „Ktorý riadok načíta vstup a ktorý nastaví LED?“

Diferenciácia a dôkaz učenia

Podpora: tabuľka pin → režim → funkcia a čiastočne pripravená kostra kódu. Základ: Karta 01. Rozšírenie: prepínanie stavov alebo dve tlačidlá. Úspech: žiak predvedie obe polohy a vysvetlí INPUT, OUTPUT aj prúdový rezistor.
